# Career Quest — приложение с API

Русский адаптивный интерфейс, светлая тема с фиолетовыми и зелёными акцентами, авторские SVG-иллюстрации. Эта версия расположена в корневых `public/` и `server.py` и запускается независимо от параллельного проекта `frontend/`.

## Запуск

Нужен Python 3.10 или новее. Для работы приложения не нужны npm, сборка и сторонние Python-пакеты.

```powershell
python server.py
```

Запустите команду из корня репозитория и откройте **http://127.0.0.1:8000**. Альтернатива: `start.ps1`.

При первом запуске создаются шесть демонстрационных сотрудников. SQLite хранится в `data/career.db`; изменения сохраняются после перезапуска. Пример импорта скачивается из HR-кабинета.

## Возможности

- Кабинеты сотрудника и HR, выбор демонстрационного профиля.
- Профиль: должность, грейд, команда, навыки, требования к следующему уровню, история.
- Карьерный маршрут и до трёх подходящих рекомендаций с обоснованием.
- Шесть активностей с материалами и проверкой знаний. Верный ответ обновляет навыки, прогресс, историю и HR-аналитику. Повторное прохождение не даёт повторных баллов, включая одновременные запросы.
- Каталог, поиск по навыкам и темам, избранное, фильтры, уведомления о завершениях.
- HR: распространённость дефицитов, отсутствие следующего шага, участие и таблица сотрудников.
- Импорт неизвестных профилей JSON/CSV, проверка полей, атомарная загрузка, защита существующих профилей от перезаписи.
- Мобильная версия, управление с клавиатуры, reduced motion.

## AI

**Без API-ключа работает локальный алгоритм по правилам, не языковая модель.** Интерфейс явно показывает демо-режим. Алгоритм исключает завершённые активности, оценивает полезный прирост для дефицитных навыков и учитывает длительность. Прогресс рассчитывается на сервере.

Для генеративных объяснений реализована прямая интеграция с Gemini через REST [generateContent](https://ai.google.dev/api):

1. Скопируйте `.env.example` в `.env`.
2. Укажите `GEMINI_API_KEY`. При необходимости измените `GEMINI_MODEL` на доступную в аккаунте модель.
3. Перезапустите сервер и нажмите **«Обновить подбор»** на странице маршрута или активностей.

Ключ остаётся на сервере. Модели отправляются должность, грейд, навыки, цели и подходящие активности; имя и история не передаются. Объяснения отображаются как текст. При ошибке или таймауте используется локальный подбор с уведомлением. Реальный вызов Gemini требует действующего ключа; без него внешняя генерация не выполняется.

Вместо Gemini можно подключить сервис третьего участника команды через `CQ_AI_URL` и необязательный `CQ_AI_TOKEN`. Он получает POST с `profile`, `recommendations`, `activities` и возвращает:

```json
{"explanations": {"research": "Почему эта активность подходит сотруднику"}}
```

## Импорт профиля

```json
[
  {
    "name": "Айдана Серикова",
    "role": "Продуктовый дизайнер",
    "grade": "Middle",
    "department": "Продукт",
    "skills": {"UX-исследования": 40, "Дизайн-системы": 35},
    "target": {"UX-исследования": 80, "Дизайн-системы": 75}
  }
]
```

Обязательные поля: `name`, `role`, `grade`, `skills`, `target`. Грейды: Junior, Middle, Senior, Lead. Навыки — целые числа 0–100, цели — 1–100. `id` необязателен и генерируется автоматически; существующие id отклоняются. Для сопоставления используйте одинаковые названия навыков. Если подходящих активностей нет, сотрудник появляется в HR-разделе без следующего шага. Достигшие целей в этот список не попадают.

CSV имеет те же заголовки, объекты `skills` и `target` записываются JSON-строками в корректно экранированных ячейках. Кодировка UTF-8, поддерживается BOM. До 200 профилей за раз; до 900 КБ содержимого файла, до 1 МБ HTTP-запроса.

## Сценарий для защиты

1. Откройте профиль Алины: готовность к Senior **78%**.
2. Посмотрите объяснение рекомендации «Система, а не набор кнопок».
3. Откройте активность, изучите материал и ответьте на вопрос о семантическом токене.
4. Прогресс станет **83%**, дизайн-системы вырастут с 40 до 60, UI-дизайн — с 80 до 85.
5. Проверьте историю и новые рекомендации. После перезагрузки результат сохранится.
6. В HR-кабинете изменится участие. У Армана нет подходящей активности — это отражается в аналитике.
7. Загрузите новый профиль через JSON и откройте его рекомендации.

Баллы обозначают учебный прогресс прототипа, а не аттестацию или автоматическое решение о повышении.

## API и структура

| Маршрут | Назначение |
| --- | --- |
| `GET /api/state` | Профили, прогресс, история, каталог и рекомендации |
| `POST /api/recommend` | Объяснения; тело `{ "employeeId": "alina" }` |
| `POST /api/complete` | Проверка ответа; `employeeId`, `activityId`, `answer` (индекс с нуля) |
| `POST /api/import` | Импорт; `format` (`json` или `csv`), `content` (содержимое файла строкой) |

- `public/index.html`, `public/styles.css`, `public/app.js` — интерфейс без сборки.
- `server.py` — API, SQLite, каталог, расчёты и AI-интеграция.
- `test_server.py` — бизнес-сценарии API в изолированной базе.
- `test_ui.py` — проверка полного сценария и мобильного интерфейса.

```powershell
python -m unittest test_server -v
# Необязательный браузерный тест:
python -m pip install playwright
python -m playwright install chromium
python test_ui.py
```

Тесты не изменяют рабочие профили. Скриншоты сохраняются в `data/`.

## Границы прототипа

Локальное демо: переключатель ролей не является авторизацией. Для публичного внедрения нужны аутентификация, серверные права доступа и производственный веб-сервер. Каталог редактируется в `server.py`; импортируются профили. Время обучения — длительность завершённых материалов, не таймер присутствия. Google Fonts имеет системный шрифт на случай отсутствия сети.
