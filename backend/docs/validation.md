# Выполненные проверки

Среда проверки: Windows, Python 3.13.8, uv 0.12.18, отдельный локальный
PostgreSQL 18.1 на 127.0.0.1:55432. Рабочая служба PostgreSQL не изменялась.
Дата проверки: 2026-09-23. Использовалась отдельная БД career_quest_test.

| Проверка | Результат |
|---|---|
| `uv sync --locked` | Успешно, 42 пакета; uv.lock создан инструментом uv |
| `uv run ruff check src tests` | Успешно |
| `uv run ruff format --check src tests` | Успешно, 57 файлов |
| `uv run mypy src` | Успешно, strict, 47 файлов |
| `uv run pytest -q` | 39 passed, 55.45 секунды, без пропусков |
| `uv run alembic check` | No new upgrade operations detected |
| Начальная миграция в пустой PostgreSQL | Успешно |
| Исходные JSON/CSV | Импорт 200 сотрудников, 60 навыков, 40 событий, 32 профилей, 2743 записей истории; повторный импорт без изменений |
| `scripts/Demo.ps1` | Полный сценарий через Uvicorn/HTTP на 127.0.0.1:8001 прошёл |
| PowerShell parser: Demo.ps1, Check.ps1 | Без синтаксических ошибок |
| Compose config | YAML проверен с `--no-env-resolution --no-interpolate --quiet` |

Тесты проверяют самооценку, независимое назначение и рассмотрение, аудит,
идемпотентность, чужие объекты/evidence, истечение и отзыв сессий, области HR,
апелляцию и версию профиля, закрытую вакансию, отдельное повышение, исключения
каталога, историю и критические разрывы, симуляцию, повторяемую активность,
конкурентное подтверждение и атомарный откат. ZIP проверяется на синтетических
архивах. AI проверяется через порт и httpx.MockTransport, включая недопустимые
ID/факты, тайм-аут и изменения профиля во время вызова.

[Замер API](benchmark-results.md) выполнен на полном наборе. Это измерение
через ASGI transport с реальной PostgreSQL; транспортная сеть не включена.
Демонстрация отдельно проверена через настоящий loopback HTTP.

При дополнительной проверке Docker стал доступен: контейнерная сборка,
миграции, healthcheck и полный HTTP demo прошли. Живая локальная модель
вернула валидированное ранжирование; отдельно подтверждён fallback при
тайм-ауте. Подробности и команды — в
[отчёте Docker/AI](docker-ai-validation.md).
Исходный архив/PDF/README датасета отсутствуют.
Эти проверки не подтверждают готовность к промышленной эксплуатации.
