# Career Quest frontend

Локальное React-приложение на React, TypeScript и Vite. Сейчас оно работает без API: стартовый датасет раздаётся Vite как статические JSON/CSV-файлы из `public/data`.

## Запуск

```powershell
cd frontend
npm install
npm run dev
```

Сборка: `npm run build`.

## Основные сценарии

- Откройте «Сотрудники», найдите человека по имени или ID и перейдите в профиль.
- В профиле показаны навыки, разрывы относительно следующего грейда, карьерная цель, история участия и до трёх рекомендаций.
- Рекомендации учитывают целевой грейд, critical skills, прирост навыка, prerequisites и предыдущие завершения/пропуски похожих активностей. Обязательные мероприятия не рекомендуются.
- «Отметить выполненной» применяет gain с ограничением max_level и записывает завершение в локальное состояние браузера.
- В «HR-аналитике» видны частые разрывы, участие по мероприятиям и сотрудники без доступного следующего шага.
- «Загрузить проверочные данные» добавляет новые профили; если employee_id уже есть, профиль и его история заменяются данными из файлов. CSV должен ссылаться на event_id каталога и содержать историю загруженных сотрудников.

Локальные изменения и загруженные профили сохраняются в localStorage этого браузера. Очистка данных сайта возвращает исходное состояние. Для подключения будущего backend достаточно заменить слой загрузки/сохранения в `src/context/CareerDataContext.tsx`; расчёты вынесены в `src/services/careerData.ts`.

## Данные

`public/data` содержит стартовые `employees.json`, `events.json`, `skills.json` и `activity_history.csv`. Набор синтетический, с датой среза 2026-10-01.
